# Contributing

Thanks for your interest in contributing to MCP SaaS Starter.

## Development

1. Install dependencies with `pnpm install`
2. Copy `.env.example` to `.env` and fill in values as needed
3. Run `pnpm build` to verify packages compile
4. Run `pnpm dev` to start apps in development mode

Contribution workflow details (branch naming, PR process, tests) will be expanded before the public v1 release.
